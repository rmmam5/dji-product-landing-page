
# DJI Mavic 4 Pro - Product Landing Page

A responsive product landing page built with HTML and CSS.

## About

This project was created as Task #3 in the Frontend Track at GDG on Campus - Benha University.

## Features

- Product details and pricing
- Accessories section
- Customer reviews and ratings
- Responsive layout
- Hover effects

## Technologies

- HTML5
- CSS3
- Flexbox

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. You can also use Live Server in VS Code.
